# 参考图几何量取（A = Clash Royale / 皇室战争）

> **本文件是"原版值"的唯一出处**，服务于 `策划/对照表.md` 的「原版值(出处)」列与各片自审的逐项比对。
> 每题给：**像素值 + 原点与参照边 + 占屏宽/高百分比 + 折算到 1080 宽画布的值 + 出处（哪张图 + 量哪条边）**。
> ⛔ **量不到的项一律写 `未量到`，并给「试过哪几张图 / 为什么量不到 / 消除条件 / 谁能给」**；⛔ 不填估计值。
> 采集时间 2026-09-21（V4 片）。**坐标原点**：图片左上角为 (0,0)，+x 向右、+y 向下（阅读图片的自然方向）。
>
> **折算口径**：基线图 `1242×2208` 与本项目竖版画布 `1080×1920` **同宽高比 0.5625** ⇒ 单一比例
> `k = 1080/1242 = 0.8696`（横向、纵向通用）。`@1080` 列 = 像素值 × 0.8696。
> **读数容差**：像素扫描/网格叠图读数 **±5px**（放大 4× 的裁图上逐格读）；超容差的差一律写成 `不一致`。
