### B.2 「骑士血量偏高」定论（数值全部由官方数据算出）

| 项 | 数值（出处） |
|---|---|
| 官方 `Knight` 11 级血量 | **1766**（`原版资源/cr-api-data/docs/json/cards_stats_characters.json:308`；同值另见 `cards_stats.json:51562`） |
| 本工程 `knight` 血量 | **1766**（`server/game/table/tsv/unit.tsv:2`）⇒ **表值 = 官方 11 级原值，没有调高** |
| 官方 `Knight` 11 级单发 | 202（`cards_stats_characters.json:329` / `cards_stats.json:51583`）= 本工程表值 |
| 公主塔单发 / 攻速 | 128（`cards_stats_projectile.json:242`）/ 800 ms（`cards_stats_building.json` `PrincessTower.hit_speed`） |
| 公主塔官方 `dps_per_level[10]` | 212（`cards_stats_projectile.json:264`）——与「128 ÷ 0.8 s = 160」不自洽（官方同文件内部矛盾，差异登记 **D3**） |
| 公主塔击杀骑士 | 需 `ceil(1766/128)` = **14 发**。口径1（本工程 128 + 800 ms）：**11.2 s**（首发含前摇）/ 首发命中后 10.4 s；口径2（官方 212 dps）：**8.33 s** |
| 国王塔击杀骑士 | **14 发 = 14.0 s**（128 单发 ÷ 1000 ms = 128 dps，官方自洽） |

> 结论：骑士 1766 = 官方 11 级原值，本工程**没有把它调高**。
> 「显得过硬」的可量化原因：骑士要挨公主塔 **14 发（≈11 s）** 才死，
> 而 3 圣水档其它卡为 archers 3 发 / goblins 2 发 / minions 2 发 / spear-goblins 2 发 / bomber 3 发
> —— 骑士是 3 费档唯一的单体高血单位；4 费档只有 valkyrie（15 发）比他更肉。
