# 原版基线图索引（交付闸门 §3 要求的「基线图」目录）

> 本目录 = **原版对照基**（A = Clash Royale / 皇室战争）在本地的一份**副本**，
> 源目录 `策划/参考图/`（采集说明见 `策划/参考图/清单.md`）。副本与原图**逐字节相同**（`Copy-Item`，未缩放未裁切）。
> 复制命令（可复算）：
> ```powershell
> Copy-Item 策划\参考图\<文件名> 策划\基线图\<文件名> -Force
> ```
> ⛔ 本目录只放**能当"原版对照基"的图** —— 即本项目**真的做了对应界面**的那些；
> A 侧未取到（登录 / 结算 / 暂停 / 设置）与 A 侧不存在（房间）的界面，**没有基线图**（见 §2）。

## 3. 与「原版素材」的分工（⛔ 两者不是一回事）

- **本目录** = **整屏参考截图**，用于判「朝向 / 布局 / 像素级尺寸」。数量少、分辨率各异。
- **原版素材** = `原版资源/`（APK 解包图集，见 `策划/原版UI素材索引.md`），用于**取像素**（九宫格切片、逐帧动画）。
- **落地素材** = `client/Assets/Resources/Sprites/`（只复制被引用的那几个），键集中在 `Core/ResPaths.cs`。
- 对照行（原版值 / 我们的值 / 差值 = 0）见 `策划/对照表.md`；逐项「一致 / 不一致」见 `策划/自审对比/`。
