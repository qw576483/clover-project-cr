## 1. 全局单位系统（★ 一切几何与速度的基准）

| 量 | 定义 | 出处 |
|---|---|---|
| **格（tile）** | 竞技场基本长度单位 | — |
| milli-tile | **1/1000 格**；官方数据里 `range` / `collision_radius` 的单位 | `cr-sim/reference/anchors.json` → `milli_tiles_per_tile: 1000` |
| subtile | 1/18000 格（本项目服务端用**整数定点**，单位取 1/1000 格 = milli-tile，足够精确且与官方数据同尺度） | `cr-sim/cr_sim/engine/fixed.py:48` `SUBTILES_PER_TILE = 18000` |
| **速度** | 单位 **格/分钟**（`tiles_per_minute_per_speed_unit: 1`） | `anchors.json` |
| **时长** | 官方数据一律 **毫秒** | `cr-sim/cr_sim/engine/constants.py:8` |
| 射程 | milli-tile（`range: 1200` ⇒ 1.2 格） | 交叉验证：弓箭手 `range=5000` ⇒ 5 格，与公开资料「攻击射程 5」一致 |
| 速度档位 | 慢 45 / 中 60 / 快 90 / 极快 120（格/分钟） | 官方数据 `speed` 字段取值 |

**Tick 率**：服务端 **20 TPS**（50ms/帧）。
- 出处：`constants.py:30` 官方所有时长都是 50ms 的倍数，20 TPS 可整除；`VERIFICATION_TPS=60` / `TRAINING_TPS=20`，两者行为等价。
- 本项目取 20 TPS（服务端 tick + 快照），客户端 60 FPS 插值。

## 4. 建筑与塔数值（★ 锦标赛标准 = **11 级**）

> ### ★ 等级口径（**已修正**，一切取值的唯一规则）
>
> 官方逐级数组**不是**统一取索引 10 —— **索引取决于稀有度**。权威出处：
> `原版资源/cr-api-data/docs/json/rarities.json` → `tournament_level_index`：
>
> | 稀有度 | `tournament_level_index`（= 11 级在数组里的下标） | `level_count`（数组长度） |
> |---|---|---|
> | Common | **10** | 15 |
> | Rare | **8** | 13 |
> | Epic | **5** | 10 |
> | Legendary | **2** | 7 |
> | Champion | **0** | 5 |
>
> **取值规则**：`值 = <字段>_per_level[ rarities[该卡稀有度].tournament_level_index ]`。
> 建筑 / 塔不是卡牌，按 `cards_stats_building.json` 自带的数组 + 其 `rarity` 字段同规则取。
>
> **交叉验证（已通过，逐字一致）**：
> - Knight（Common，索引 10）：`hitpoints_per_level[10] = 1766` / `damage_per_level[10] = 202`
>   ↔ `cr-sim/reference/anchors.json` 手工实测 `1766 HP / 202 damage / 168 DPS / 1.2s` ✅
> - P.E.K.K.A（Epic，索引 5）：`hitpoints_per_level[5] = 3760` ↔ anchors 手工实测 `3760` ✅
>   （若按索引 10 误取会得 6016，**错 60%** —— 这正是本条被修正的原因）
> - Rocket（Rare）/ Arrows（Common）伤害亦与 anchors 逐字一致。
>
> ⚠️ **修正记录**：本文件初版写的「一律取索引 10」**只对 Common 成立**，已由 agent-01 实测发现、
> 主 agent 复核 `rarities.json` 确认后改正。

## 5. 单位战斗规则（本项目核心逻辑的判据）

| 机制 | 规则 | 出处 |
|---|---|---|
| 索敌 | 在 `sight_range` 内取**距离最近**的合法目标；`target_only_buildings` / `target_only_towers` / `target_only_troops` / `attacks_air` / `attacks_ground` 过滤 | 官方字段名：`sight_range` / `target_only_buildings` / `target_only_towers` / `target_only_troops` / `attacks_air` / `attacks_ground` |
| 攻击条件 | 目标进入 `range` 后开始攻击；先用 `load_time` 做**首次攻击前摇** | 官方 `range` / `load_time`（弓箭手 load_time=900ms，Knight=700ms） |
| 攻击节奏 | 每 `hit_speed` 造成一次 `damage` | 官方 `hit_speed` / `damage` |
| 近战射程档 | 短 800 / 中 1200 / 长 1900（milli-tile） | `anchors.json` → `melee_range_short/medium/long` |
| 投射物 | `projectile` 非空 ⇒ 远程，弹道速度 = `projectile.speed`，命中后结算 | 官方 `cards_stats_projectile.json` `speed` |
| 群体卡 | 一张卡召唤 `summon_number` 个 `summon_character`，围绕落点按 `summon_radius` 环形铺开（无 radius 时按半径推导） | 官方 `cards_stats_troop.json` `summon_number` / `summon_radius`；`cr-sim/cr_sim/engine/fixed.py:217` `ring_offsets` |
| 部署延迟 | 落点后 `deploy_time`（官方普遍 1000ms）才出现并可行动 | 官方 `deploy_time` |
| 移动 | 地面单位沿车道 → 最近桥 → 目标点寻路；**飞行单位无视地形**（可直接过河） | `arena.py:183-210` `is_walkable(flying=)` |
| 推挤/碰撞 | 单位间按 `collision_radius` + `mass` 分离 | 官方 `collision_radius` / `mass` |
| 击退 | 按 origin→point 方向外推 `pushback` | `fixed.py:132` `push_away` |
| 亡语 | 官方 `spawn_character` / `spawn_number` / `area_effect_on_death`（骷髅巨人、气球兵、天狗分裂等） | 官方字段 |
| 法术 | `instant_damage` / `duration_seconds` / `heal_per_second` / `spawn_character`；法术可落河面与敌方半场 | 官方 `cards_stats_spell.json` |
| 塔的目标优先级 | 塔只攻击进入其 `range` 的**最近**敌方单位 | 公开资料 |

## 8. 允许的差异（★ 必须逐条登记：是什么 + 为什么 + 出处 + 何时消除）

| # | 差异 | 为什么 | 出处 | 何时消除 |
