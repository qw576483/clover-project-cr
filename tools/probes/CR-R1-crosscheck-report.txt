# Defects found in THIS verifier by its own negative tests:
#   1) empty string is a member of the forbidden-char set in python -> line-end tokens were
#      misfiled as patterns and NEGATIVE TEST 1 stopped being able to fail.
#   2) ambiguous candidates were whitelisted repo-wide; cleanup only empties .ai-tmp/* -> bloat.
#   3) the two whitelist producers disagreed on the path separator -> 43 duplicate entries.
#   4) an ASCII comma inside {a,b,c} is punctuation everywhere else, so a single character
#      class could not capture the brace form whole: bucket A read 0 while the same citations
#      were reported as truncated literals (a phantom-missing generator).  Fixed by matching
#      the whole brace form FIRST, then a glob, then an ordinary name.
